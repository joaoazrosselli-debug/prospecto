# Como contribuir

1. Faça um fork e crie uma branch com uma alteração bem delimitada.
2. Leia o README e o mapa do código. Preserve os controles de acesso e o isolamento das prévias.
3. Utilize dados fictícios. Não inclua credenciais, bancos, backups, arquivos de clientes nem identificadores da hospedagem privada.
4. Execute as verificações adequadas à mudança. Se houver alteração visual, mostre o resultado no desktop e no celular.
5. Abra um pull request explicando problema, comportamento esperado e verificações realizadas.

Um repositório público permite consultar e propor mudanças; não dá permissão para gravar diretamente no código principal ou acessar a operação privada. Não existe implantação automática a partir deste repositório.

Não remova autenticação, permissões, proteção de origem, validações de mídia, sandbox ou CSP para fazer uma funcionalidade passar. Proponha a mudança e explique o motivo para revisão.
